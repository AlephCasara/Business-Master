# README visual assets

These SVGs are repository-owned presentation assets for the root `README.md`.

- `hero-light.svg` / `hero-dark.svg` — project identity and top-level control-loop motif.
- `control-loop-light.svg` / `control-loop-dark.svg` — canonical closed economic control loop.
- `architecture-light.svg` / `architecture-dark.svg` — control plane and execution-engine architecture.

Design constraints:

- self-contained SVG only;
- no external fonts or image dependencies;
- light/dark variants must convey the same semantics;
- diagrams describe architecture, not runtime proof;
- a real closed-loop demo should only be added after the PR10 autonomy milestone is satisfied against an external surface.
