# README presentation notes

The root README is intentionally a project front door rather than the canonical specification.

Detailed economic, architectural, runtime, engine, and research material remains in the existing canonical docs. The README should stay optimized for progressive disclosure:

1. identity and one-line definition;
2. canonical control loop;
3. evidence model and architectural overview;
4. honest implementation status;
5. quickstart and documentation map.

The README must not claim a real autonomous closed loop before the PR10 milestone is satisfied. Once external evidence can autonomously cause a child experiment without a new human prompt, replace the current autonomy-proof diagram with a short real recording and measured runtime statistics.
